# JulogicTUNNEL

**An open-source VPN application for Android.**

JulogicTUNNEL is an Android VPN application project focused on providing a simple user experience, transparent development, and continuous improvements driven by the community.

The project welcomes developers, testers, security researchers, and users interested in contributing to its evolution.

> **Project status:** Under development. Features, compatibility, and availability may vary between versions.

## 🚀 Getting Started

### Requirements

- An Android device compatible with the minimum supported Android version.
- An APK file obtained from a trusted source.
- An Internet connection to use VPN features.
- Access to a compatible VPN server or service, depending on the application's implementation.

### How to Use

1. Install and open JulogicTUNNEL.
2. Review the instructions and permissions requested by the application.
3. Configure or select a supported VPN connection, if required.
4. Start the connection and authorize VPN usage in Android settings when prompted.
5. Verify that the connection is working correctly.

The exact steps may vary depending on the application version and server configuration.
